## 概述

在 Unity 中开发游戏时，您不可避免地要多次重复使用相同的配置对象--敌人角色、子弹、硬币、树木和岩石等背景对象。手动复制粘贴每个对象的位置非常乏味，而且当您后来决定 "我想稍微改变一下敌人的 HP "时，修改场景中的每个敌人就成了一场噩梦。

预制件巧妙地解决了这一问题，是 Unity 最强大、最重要的功能之一。Prefab 就像一个 "蓝图 "或 "模板"，它将 GameObject 与其组件和属性设置捆绑在一起。本文涵盖了从基本的 Prefab 概念到创建、使用以及最大限度提高开发效率的高级技巧等所有内容。

## 什么是预制件

Prefab 是一种可重复使用的 GameObject 资产。在 `层次结构` 窗口中创建并配置一个 GameObject，然后将其拖放到 `项目` 窗口中即可创建一个 Prefab。

一旦预制化，您就可以像盖章一样在场景中放置（实例化）该预制资产，需要多少次都可以。最强大的一点是：当您修改原始预制资产（蓝图）时，更改会自动传播到从中创建的所有实例（场景对象）。

### 使用预制件的好处

- **可重复使用**: 轻松在场景中重复放置相同的对象。
- **批量编辑**: 编辑原始预制件，同时更新所有实例。这样创建的项目既能适应规格变更，又具有很高的可维护性。
- **动态生成**: 在游戏过程中使用 `Instantiate()` 从预制件动态创建物体。这对子弹发射、敌人生成等至关重要。

## 创建和使用预制件

### 1. 创建预制件

1. **准备对象**: 在层次结构中创建要预制的游戏对象，添加必要的组件（脚本、碰撞器等），并在检查器中配置值。
2. **预制化**: 将已配置的 GameObject 从 Hierarchy 拖到 Project 窗口中的任意文件夹（通常创建一个 Prefabs文件夹）。

这样就在项目窗口中创建了一个带有蓝色立方体图标的预制资产。同时，`层次结构` 中的原始对象也变为蓝色图标，表明它现在是一个预制实例。

### 2. 实例化(放置)预制件

- **手动放置**: 将预制资产从 "项目" 拖至 "场景" 视图或 "层次结构"。
- **动态生成**: 从脚本中使用 `Instantiate()`

```c#
using UnityEngine;

public class Spawner : MonoBehaviour
{
    // Prefab set in Inspector
    // 在检视面板中设置预制件
    public GameObject enemyPrefab;

    void Start()
    {
        // Start coroutine spawning enemies every 3 seconds
        // 启动协程，每3秒生成敌人
        StartCoroutine(SpawnEnemies());
    }

    IEnumerator SpawnEnemies()
    {
        while (true)
        {
            // Create new instance from Prefab
            // 从预制体创建新实例
            Instantiate(enemyPrefab, transform.position, Quaternion.identity);
            yield return new WaitForSeconds(3f);
        }
    }
}
```
## 编辑预制件和 Overrides

### 编辑预制件

通过以下方式编辑预制资产

- **预制模式**: 双击项目中的 Prefab 资产，或在层次结构中选择一个 Prefab 实例，然后单击检查器中的 "打开"，即可进入专用的 "Prefab 模式"。在此进行的更改会影响所有实例。

### Overrides

有时，您只想更改预制设置中的特定实例--"给这个敌人更多的 HP "或 "让这棵树变大"。

在 "检查器" 中更改场景 Prefab 实例的值时，这些属性会以粗体显示，表示已被覆盖。这些更改仅适用于该实例--原始 Prefab 和其他实例不受影响。

要将覆盖应用到原始预制板，请从检查器顶部的 Overrides下拉菜单中选择 `Apply All`。要放弃覆盖并恢复到预制件设置，请选择 `Revert All`。

## 高级: 嵌套预制件和预制件变体

Unity 2018.3 让 Prefabs 变得更加强大：

- **嵌套预制件**: 将预制件放入其他预制件中。例如，创建一个 "Gun" 预制件，然后将其并入 "Soldier "预制件。这样就能实现更多的模块化组件组装。
- **预制件变体 Variants**: 在另一个预制件的基础上创建 "变体"预制件，只存储不同之处。例如，基础 "普通哥布林 "预型→"红色哥布林 "变体（只有材料颜色不同）、"哥布林弓箭手 "变体（携带弓箭）。当您更改 "普通哥布林 "基础版的 HP 时，该更改会继承到所有变体--管理效率极高。

## 总结

预制件体现了 Unity 中面向对象的思想，是高效、可扩展游戏开发的基础。

- 预制件是可重复使用的物体 "蓝图"。
- 编辑原始 Prefab 以批量更新所有实例。
- Instantiate()在游戏过程中动态生成对象。
- Overrides 只允许修改特定实例。
- Variants 可以有效地管理从基本预制件继承而来的不同预制件。

养成用 Prefabs 管理游戏中所有对象（玩家、敌人、物品、用户界面元素）的习惯，是超越初级水平的重要一步。
