## 概述

随着 Unity 游戏开发的进展，各种资产类型（文件）成倍增加--脚本、三维模型、纹理、材质、Prefabs。随着项目的增加，如果不对这些资产进行整理，就无法找到任何东西，严重降低了开发效率。

本文介绍了 Unity 项目组织的基本 "场景 "概念，以及使资产管理更轻松的 "文件夹结构 "的最佳实践。良好的组织不仅能提高个人开发效率，也是团队顺利开发的必备技能。

## 什么是场景(Scene)

Unity 中的 **Scene** 是由游戏 "场景" 或 "关卡 "组成的一个单元。例如，每个场景都是作为单独的场景创建的：

- Title Screen
- Game Stage 1
- Game Stage 2
- Game Over Screen
- Settings Screen

每个场景文件（扩展名为 `.unity`）都存储了该场景的所有游戏对象、灯光、摄像头、用户界面层次结构和组件设置。实现场景转换--当玩家通关一个阶段时，从当前场景切换到下一阶段场景--可使游戏取得进展。

### 创建和管理场景

- **创建**: 在项目窗口中单击右键，选择 `Create > Scene`
- **保存**: 使用 `File > Save` 或 `Ctrl + S` 快捷键 将更改保存到当前打开的场景中。
- **切换**: 双击项目窗口中的场景文件可切换编辑器

要在游戏过程中切换场景，请使用 `SceneManager` 类。这将在另一篇文章中详细介绍。

## 项目文件夹结构

将所有资产直接放入项目根目录 (`Assets`文件夹) 是最糟糕的做法。按类型将资产整理到文件夹中可以让您快速找到目标文件。这是全球 Unity 开发人员采用的事实上的标准做法。

下面是一个常见的、易于理解的基本文件夹结构：

```
Assets
├── Scenes          # 场景文件 (.unity)
├── Scripts         # C# 脚本 (.cs)
├── Materials       # 材质 (.mat)
├── Prefabs         # 预制件 (.prefab)
├── Textures        # 纹理图片 (PNG, JPG, etc.)
├── Models          # 3D 模型 (FBX, OBJ, etc.)
├── Audio           # 音频文件 (WAV, MP3, etc.)
│   ├── BGM         # Background music
│   └── SFX         # Sound effects
└── Shaders         # Custom shaders (.shader)
```

### 为什么这种结构行之有效

- **直观清晰**: 文件夹名称与资产类型相匹配，一目了然。
- **高度可搜索性**: 想修改脚本? 查看 `Scripts` 文件夹。更改材质颜色? 查看 `Materials` 文件夹。减少搜索时间。
- **团队友好型**: 当所有团队成员都遵循相同的文件夹规则时，查找其他人创建的文件就变得非常容易，从而实现顺畅的协作。

### 基于特征的文件夹结构（中大型项目）

随着项目规模的扩大，仅对资产类型进行组织可能会变得困难。例如，将数百个脚本平放在 `Scripts` 文件夹中，就很难找到相关的脚本。

```
Assets
└── Features
    ├── Player
    │   ├── Scripts
    │   ├── Prefabs
    │   └── Materials
    ├── Enemy
    │   ├── Scripts
    │   ├── Prefabs
    │   └── Models
    └── TitleScreen
        ├── Scripts
        ├── Scenes
        └── Textures
```
这种方案会将所有和玩家相关的内容统一收纳至 `Features/Player` 文件夹内。相关资源集中存放，大幅提升功能修改与新增功能的工作效率。

哪种结构更好取决于项目规模和团队文化，但首先要从基本的资产型组织开始。

## 最佳实践和技巧

- **从一开始就整理**: "我稍后再整理" 永远不会发生。养成在导入或创建资产时立即将其移动到正确文件夹的习惯。
- **明确命名约定**: 文件夹和文件名也很重要。对于与玩家相关的脚本，使用 `PlayerController`、 `PlayerHealth` 这样的前缀可以提高可视性。
- 使用 `_` : 用 `_ThirdParty` 或 `_Sandbox` 等下划线作为文件夹名的前缀，可将其按字母顺序排列在最前面--这对于区分外部导入的资产或临时实验文件夹非常有用。

## 总结

正确的项目管理是简洁、高效开发的基础。场景和文件夹结构是第一步。

- **Scenes**: 管理游戏 "场景 "和 "关卡 "的单元。
- 文件夹结构: 基本方法是按类型将资产整理到文件夹中。
- 养成习惯: 尽早开始组织工作有助于未来的自己和团队。

整洁的项目可以更容易地发现错误，并加快新功能的开发。从今天开始，成为 "组织大师"
