## 概述

在动作游戏中，玩家击中敌人或受到伤害时的 "冲击力 "是一个关键因素，会极大地影响游戏的满意度。传达这种冲击力的最简单但最有效的技术之一就是白光闪，即角色短暂发出白光。

在 Godot 中，只需几行代码和 `Tween`属性，您就可以轻松实现这种白色闪光效果，而无需艰深的着色器知识。关键在于 `modulate`属性。

## `modulate`属性如何工作

`modulate`是所有从 `CanvasItem`继承而来的 2D 节点（ `Sprite2D`、 `Label`、 `ColorRect`等）的标准属性。通过为该属性设置 `Color`，可以乘以该节点（及其所有子节点）的色调。

- `modulate = Color(1, 1, 1)`（白色）：与原始颜色相同（默认状态）
- `modulate = Color(1, 0, 0)`（红色）：只保留纹理的 R 分量，呈现淡红色调
- `modulate = Color(0.5, 0.5, 0.5)`（灰色）：整体颜色较深
- `modulate = Color(1, 1, 1, 0.5)`（半透明）：Alpha 值控制透明度

### 为什么会泛白？HDR（高动态范围）效果

`modulate`属性最有趣的特点是颜色值可以设置为 1 以上。通常，颜色的表达范围是从 0（无光）到 1（原色），但如果将 `modulate`的 RGB 值设置为 1 以上，精灵就会被视为 HDR（高动态范围）颜色，并开始发光，就像从内部照亮一样。这会产生一种 "渲染 "的效果，这也是白光闪烁的原理。

例如，设置 `modulate = Color(10, 10, 10)`后，无论原始纹理的颜色如何，精灵都会发出几乎纯白色的光。

## 基本实现：使用 Tween 平滑过渡

白色闪光是 "瞬间变白，然后平滑地恢复到原来的颜色 "的动画序列。为了实现这种基于时间的处理，Godot 提供了一个非常强大和方便的功能 `Tween`。

下面是一个可重复使用的函数，它可以对受到伤害的角色（一个带有 `Sprite2D`并命名为 `sprite`的节点）施加白闪：

```gdscript
# CharacterBody2D 等

# 将补间动画作为实例变量进行管理（用于控制连续伤害判定）
var flash_tween: Tween

# 受到伤害时外部调用的函数
func apply_damage_effect():
    # ……扣减生命值、开启无敌时长等运算处理……
    # 开始白色闪光处理
    _start_white_flash()

# 执行白色闪光的内部函数
func _start_white_flash():
    # 取消所有正在运行的补间动画
    if flash_tween and flash_tween.is_valid():
        flash_tween.kill()

    # 1. 一键将精灵图变为白色
    $Sprite2D.modulate = Color(10, 10, 10) # Large values make it glow white

    # 2. 创建补间动画并制作动画，实现平滑恢复至原始颜色
    flash_tween = create_tween().set_trans(Tween.TRANS_QUINT).set_ease(Tween.EASE_OUT)

    # 在0.3秒内将$Sprite2D的调制属性改为Color(1, 1, 1)
    flash_tween.tween_property($Sprite2D, "modulate", Color(1, 1, 1), 0.3)
```

### 代码解释

1. `flash_tween`实例变量管理 Tween。这样，当受到连续伤害时，就可以取消之前的 Tween 并开始新的闪光。
2. 调用 `_start_white_flash`时， `$Sprite2D.modulate`首先会被设置为数值非常大的 `Color`。这将立即使精灵发出白光。
3. `create_tween()`创建一个新的 `Tween`对象。在这里，方法链 `set_trans`和 `set_ease`配置了动画的缓和效果。 `TRANS_QUINT`和 `EASE_OUT`的组合创建了快速开始和缓慢结束的锐利运动。
4. `tween_property()`是动画的核心。该方法指定 "在多长时间内 "将 "哪个对象的""哪个属性 "改变为 "什么值"。
5. `Tween`在创建时自动播放，完成后自动销毁，因此执行工作已经完成。

>注意：如果 `Color(10, 10, 10)`等较大数值不起作用，可能是项目设置中禁用了 HDR。在这种情况下，请尝试使用 `Color(2, 2, 2)`至 `Color(3, 3, 3)`左右的数值。

## 常见错误和最佳做法

虽然使用 `modulate`的效果很简单，但编写更精炼的代码也有几个要点。让我们比较一下初学者常见的错误和推荐的设计。

| 常见错误                                      | 最佳实践                                                                                   |
| :---------------------------------------- | :------------------------------------------------------------------------------------- |
| 使用 `_process`中的计数器变量手动制作动画                | 使用 `Tween`或 `AnimationPlayer`声明性地描述动画                                                  |
| 将 `modulate`直接设置为 `Color(0,0,0)`，使其变黑/不可见 | 要呈现白色，RGB 值必须大于 `1`。即使在变暗时，保留一些亮度，如 `Color(0.1, 0.1, 0.1)`而不是 `Color(0,0,0)`，也能获得更好的质感 |
| 在同一功能中混合损伤处理和效果处理                         | 使用 `Signal`将损坏检测逻辑与视觉效果分开。这样可以防止效果变化影响逻辑                                               |
| 重复调用 `create_tween()`而不清理                 | 当效应接连出现时，在创建新效应之前，先 `kill()`现有的 `Tween`，以防止意外行为的发生                                     |

## 与其他模式的比较

`modulate`并非实现白色闪光的唯一方法。让我们与典型的替代方法：**着色器**

| 特点       | `modulate`+ `Tween`     | 自定义着色器                           |
| :------- | :---------------------- | :------------------------------- |
| **易用性**  | 非常简单。只需几行 GDScript 即可实现 | 需要学习着色器语言（Godot 着色器语言）           |
| **性能**   | 非常轻巧。即使有很多物体，也很少出现问题    | 取决于着色器的复杂程度。简单的较轻，复杂的可能较重        |
| **表现力**  | 仅限于颜色倍增和 Alpha 值变化      | 无限。对任何视觉效果进行像素级控制：轮廓、溶解、发光等。     |
| **建议用途** | 简单效果，如伤害闪光、物品拾取发光       | 精心设计的视觉效果，如特殊的 BOSS 入口特效、自定义粒子表情 |

从易用性和性能的角度来看，对于大多数损坏闪存表达式， `modulate`和 `Tween`组合是最佳选择。

## 总结和后续

本文介绍了如何使用 Godot 的 `modulate`属性和 `Tween`来实现白色闪光效果。这种技术是向玩家提供清晰反馈和提高游戏满意度的一种经济有效的方法。

- **`modulate`**：一种可乘以 `CanvasItem`颜色的属性。数值大于 1 时，会产生 HDR 效果的白光。
- `Tween`: 一个强大的工具，可以随时间平滑地改变属性。

在掌握了这一简单而深刻的技巧后，可以考虑挑战一下自己的这些话题：

- 添加音效：在白光闪烁的同时播放简短的音效，会使反馈效果更加丰富。
- 使用 `AnimationPlayer`：适合管理由多个动画（如闪烁、颜色变化和晃动）组合而成的复杂序列。
- 着色器入门：当 `modulate`还不够时，请进入着色器的世界。让角色轮廓发光，添加噪音--表达的范围变得无限宽广。
